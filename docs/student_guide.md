# Winter 智齿分类教学系统 — 学生使用指南

> 本系统基于 YOLOv8 + 域内预训练微调，用于口腔外科课堂的阻生智齿（Winter 分类）辅助判读教学。
> 检测模型：219 张全景片 / 384 颗智齿标注训练；角度分类准确率 ~95%（近中/垂直为最常见易混对）。

## 1. 访问系统

老师在课堂上会给出地址，浏览器打开即可（无需安装任何软件）：

```
http://<服务器地址>:8501
```

## 2. 操作步骤（3 步出结果）

1. 左侧「功能导航」选择 **🦷 Winter 教学诊断**；
2. 在右侧 **📤 上传全景片** 区域拖入一张全景 X 光片（JPG / PNG / BMP）；
3. 点击 **⚡ 开始 Winter 诊断**。

片刻后右侧显示：
- **标注图**：每颗智齿一个彩色框，框上方标注「智齿编号 · 图中方位 · 角度诊断 · 置信度」；
- **诊断明细**：逐颗列出 智齿 #1/#2…、图中左/右侧、阻生角度与置信度。

> 若未检出智齿，可把「检测置信度阈值」滑块调低（如 0.30 → 0.15）再试一次。

## 3. 结果怎么读

### 五类阻生角度（Winter 分类）

| 框颜色 | 中文诊断 | 英文 | 典型特征（读片要点） |
|---|---|---|---|
| 🔵 蓝 | 近中阻生 | Mesioangular | 牙长轴向前倾斜，与邻牙成角，**最常见** |
| 🟢 绿 | 垂直阻生 | Vertical | 牙长轴大致直立，仅位置不足 |
| 🟠 橙 | 水平阻生 | Horizontal | 牙体横卧，与邻牙垂直成角 |
| 🟣 品红 | 倒置阻生 | Inverted | 牙冠向下、根朝上 |
| 🔴 红 | 颊舌向阻生 | Buccolingual | 向颊侧/舌侧偏斜（全景片需结合口内或 CBCT 确认） |

### 两个数字代表什么

- **检测置信度**：模型"这里确实有一颗智齿"的信心；
- **角度置信度**：模型对该颗智齿角度分类的信心（如 96% = 较有把握）。

### 注意事项

- 「图中左侧/右侧」指影像上的方位；全景片左右镜像约定随设备而异，判读时可与原始片子核对；
- AI 结论是**辅助参考**，请务必结合影像特征自己独立判读后再对照。

## 4. 课堂自检建议

1. 先不看 AI 结论，对每颗智齿自己给出 Winter 角度诊断，再与 AI 对照；
2. 特别留意 **近中 vs 垂直** 的边界案例（模型最常在两者间犹豫，也是临床上容易判错的点）；
3. 遇到 AI 与自己的判读不一致时，说出理由——这就是最好的学习点。

## 5. 用自己微调的模型诊断（进阶 / 课堂作业）

如果你（或全班）自己标注数据并微调出了专属模型，在同一个网页里就能切换到自己的模型来诊断：

1. 左侧导航进入 **🧪 Winter 微调**，按页面提示上传自己的标注数据并完成微调
   （产物是 `exp_<学号>` 实验，详见 `docs/winter_web_finetune.md`）；
2. 微调完成后点页面里的 **「🦷 去 Winter 教学诊断」**，会自动切到诊断页并把
   「🔬 使用模型」选为你的 `exp_<学号>`；
3. 也可以随时在诊断页顶部手动切换：**🧪 我的实验 exp_<学号>** vs 🏫 教师演示 expA/expB，
   用同一张新全景片对比不同模型的结论；
4. 上传一张**没训练过的新全景片**，点「⚡ 开始 Winter 诊断」——这次跑的是你自己的模型。

> 提醒：只有训练时见过的图片在别的片子上表现正常，模型才算"学会了"；拿没见过的全景片测试，
> 才是检验自己标注质量的正道。

## 6. 常见问题

| 问题 | 处理 |
|---|---|
| 页面打不开 | 检查网络/地址；告知老师重启服务 |
| 上传后提示"未检测到智齿" | 调低置信度阈值重试；确认是全景片而非口内小牙片 |
| 只画框、没有角度结论 | 服务器缺角度分类权重，告知老师检查 `weights/demo/expB-cls-angulation/weights/best.pt`（随仓库提交）或 `runs/winter/expB-cls-angulation/weights/best.pt`（本机训练产物） |
| 想换模型对比 | 页面上方「🔬 使用模型」下拉切换（自己的 exp_<学号> 与教师演示 expA/expB）；特殊路径可用「高级」区手动填写 |

---

*教师端部署：服务器上 `cd` 到项目目录 → 确认权重存在 → `python run.py`（或 `streamlit run web_ui.py --server.port 8501`），并把 8501 端口开放给学生即可。*

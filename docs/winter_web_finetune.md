# Winter 微调课堂流程 — 学生自己标注、自己微调、上传新片看诊断

> 目标：每个学生在自己的（免费云 GPU 的）Web 实例里，完成
> **标注 → 上传 → GPU 微调 → 看曲线/混淆矩阵 → 用自己微调的模型诊断新全景片**。
> 训练完全在本机 GPU 上跑，全班互不排队；模型按 `exp_<学号>` 隔离。

## 0. 一次课堂的总体分工

| 角色 | 做什么 |
|---|---|
| 老师 | ① 分发整套代码（本仓库）+ 练习用全景片（建议 15-30 张、覆盖多种角度）；② 公布标注类别顺序；③ 准备 2-3 张典型片统一判读标准 |
| 学生 | ① 在自己租的云 GPU 上启动 Web；② makesense 等工具标注老师发的同一批全景片；③ 上传自己的标注 → 微调；④ 上传**没训练过**的新全景片，看自己模型的诊断结果 |

> 想对比"谁标得准"：因为全班标的是同一批图，微调后用同一张新片分别跑各自的
> `exp_<学号>` 模型，输出差异基本来自标注质量 —— 这就是课堂讨论点。

## 1. 学生端：启动 Web（云 GPU 上）

```bash
python run.py        # 缺失的依赖会尝试从阿里云镜像自动安装；启动后访问提示的地址（默认 8501 端口）
```

浏览器打开后在侧边栏把「学号/ID」改成自己的学号（如 `20230001`）。
侧边栏导航第 **3** 项「🧪 Winter 微调」——这是本轮课堂的主要页面。

## 2. 标注（在 makesense.ai 或 X-AnyLabeling）

1. 把老师发的全景片上传到标注工具；
2. **类别顺序就是标签 ID，务必与下面完全一致**（5 类 Winter 角度，只标角度一维）：
   ```
   0 = Mesioangular 近中阻生
   1 = Vertical     垂直阻生
   2 = Inverted     倒置阻生
   3 = Horizontal   水平阻生
   4 = Buccolingual 颊舌向阻生
   ```
   ⚠️ 在 makesense 里按这个顺序逐个添加标签；**顺序错了模型会把角度"学反"，而且不会报错**。
3. 每张全景片只框**智齿（第三磨牙）**，框包住整颗牙（含牙根），左右两颗都要标；没有就不标；
4. 导出 YOLO 格式 → 得到一堆与图片同名的 `.txt` 文件（若附带 `labels.txt` / 类别清单文件，忽略即可）。

> 注意：`docs/winter_annotation_guide.md` 描述的是科研用 45 组合完整方案（关系×位置×角度），
> **课堂微调只按上面的 5 类角度标注**，不要按那份文档标。

> 拿不准的角度不要乱选；标注前先和老师确认 2-3 张典型片的标准。

## 3. 上传数据并微调（页面内完成）

到「🧪 Winter 微调」页，三种数据来源任选其一：

- **上传完整 ZIP（含 images + labels）**：把图片与标签按 `images/trainset/`（或 `images/train/`）+ `labels/trainset/` 打包上传（参考「模型训练」页的目录约定）；
- **图像已在服务器 + 仅上传标注 ZIP（推荐）**：把老师分发的全景片放进本机某目录（如 `student_images/`），在页面填该目录路径；再把标注工具导出的 .txt 打包成 `labels.zip` 上传；
- **使用服务器路径**：直接填图片/标签两个目录路径（如 `dataset/images/trainset` + `dataset/labels/trainset` 可先体验内置样例数据）。

上传后页面会显示**每类角度的框数分布**——先核对一眼：类别不该全挤在 0/1，说明标注或顺序有问题。

左侧「微调参数」：

- 实验名默认取你的学号 → `exp_<学号>`；
- 初始权重选 **auto**（本机有域内预训练就用，没有则自动回落官方 COCO 权重，云端首次使用最省事）；
- 免费云 GPU 显存一般够：检测轮数 60 / 批次 16、分类轮数 60 / 批次 32，通常 5-15 分钟跑完；
  显存不足就把批次减半；只是想快速看效果可把轮数降到 20-30。

点 **🔥 开始 Winter 微调**。过程是阻塞的，建议另开一个浏览器标签到「📊 训练监控」，
目录填 `runs/winter` 并勾选「自动刷新」，实时看 loss/mAP 曲线；当前页训练完会自动展示：

- 检测 mAP50 / mAP50-95；
- 角度分类 top1（对每颗智齿裁切的 5 类角度判对率）+ **混淆矩阵热图**（看哪两类最易混，
  通常 Vertical ↔ Mesioangular）；
- 权重与指标文件的保存路径。

> 报错怎么办：OOM（显存不足）→ 减小批次；"只出现 1 种角度"→ 去补标另一种角度或修正类别顺序。

## 4. 上传新全景片，看自己模型的诊断

训练完成后点页面里的 **「🦷 去 Winter 教学诊断，上传新全景片试我的模型」**，
页面会自动切到 Winter 教学诊断并把「模型来源」选中你的 `exp_<学号>`。

1. 「🔬 使用模型」下拉确认是 **🧪 我的实验 exp_<学号>**（也可随时切回 🏫 教师演示 expA/expB 对比）；
2. 右侧上传一张**没训练过的新全景片**，点「⚡ 开始 Winter 诊断」；
3. 得到每颗智齿的彩色框 + 中文 Winter 角度结论 + 置信度；
4. 课堂自检：先自己判读再对照 AI，特别留意近中 vs 垂直这类边界。

## 5. 常见问题

| 问题 | 处理 |
|---|---|
| 页面打不开 / 依赖装不上 | 确认网络可用阿里云镜像；把云 GPU 实例的 8501 端口开放或按平台说明做端口转发 |
| 上传后提示图片与标签不配对 | 图片文件名与 .txt 必须**同名**；确认上传的 zip 结构符合页面提示 |
| 只画框、没有角度结论 | 该实验没跑角度分类权重或它缺失；重新微调，或在高级区确认 `-cls-angulation/weights/best.pt` 路径存在 |
| 训练报"只出现 1 种角度" | 标注里只有一种 Winter 角度，无法训练分类器；补标其他角度或检查类别顺序 |
| 想删掉自己之前的实验 | 手动删除 `runs/winter/exp_<学号>*`（含 `_data`）即可，或老师统一清理 |
| 电脑没 GPU 也能试吗 | 可以，设备填 `cpu`，但速度慢很多（仅建议极小数据体验流程） |

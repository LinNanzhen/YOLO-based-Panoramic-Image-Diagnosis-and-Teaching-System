# Winter 分类标注规范（给标注者）

本文档说明如何对全景 X 光片标注智齿（第三磨牙）及其 Winter 分类。
标注结果将用于训练 YOLO 检测模型。

## 1. 标什么

- **只框智齿（第三磨牙）**：每张全景片通常有 2 颗（左下、右下），各一个框。
- 框要**包住整颗牙**（牙冠 + 牙根），略留 2-3 像素边距即可，不要框住邻牙。
- 若该侧无第三磨牙（缺失/未萌出/已拔除），**不标框**。
- 一张图里左右两颗都要标，不能只标一侧。

## 2. Winter 组合类别（每个框选一个）

每个框的类别 = 关系 + 位置 + 角度 的组合，命名格式：`关系-位置-角度`，如 `II-B-近中`。

### 关系（Winter Class I / II / III）—— 与下颌支、第二磨牙的关系

| 类别 | 判断标准 |
|---|---|
| **I** | 下颌支前缘与第二磨牙远中之间有**足够间隙**，容得下第三磨牙牙冠 |
| **II** | 间隙**小于**第三磨牙牙冠的近远中宽度，牙冠部分被下颌支遮挡 |
| **III** | **没有间隙**，第三磨牙大部分位于下颌支内 |

### 位置（A / B / C）—— 深度，以第二磨牙为参照

| 类别 | 判断标准 |
|---|---|
| **A** | 第三磨牙最高点 **齐平或高于** 第二磨牙咬合平面 |
| **B** | 位于第二磨牙**咬合平面与牙颈部之间** |
| **C** | 位于第二磨牙**牙颈部以下** |

### 角度（长轴方向）

| 类别 | 判断标准 |
|---|---|
| **近中** | 牙长轴向近中（前方、向中线）倾斜 |
| **远中** | 牙长轴向远中（后方）倾斜 |
| **垂直** | 牙长轴大致垂直（与邻牙平行） |
| **水平** | 牙长轴水平/接近水平，牙冠朝向近中或远中 |
| **倒置** | 牙冠朝下、牙根朝上（少见） |

## 3. 标注工具（X-AnyLabeling）

1. 安装 X-AnyLabeling，打开 `annotated_presets/images/` 目录。
2. 配置类别列表：把以下 45 个名称**按顺序**粘贴为类别（顺序即 ID，不能乱）：
   ```
   I-A-近中, I-A-远中, I-A-垂直, I-A-水平, I-A-倒置,
   I-B-近中, I-B-远中, I-B-垂直, I-B-水平, I-B-倒置,
   I-C-近中, I-C-远中, I-C-垂直, I-C-水平, I-C-倒置,
   II-A-近中, II-A-远中, II-A-垂直, II-A-水平, II-A-倒置,
   II-B-近中, II-B-远中, II-B-垂直, II-B-水平, II-B-倒置,
   II-C-近中, II-C-远中, II-C-垂直, II-C-水平, II-C-倒置,
   III-A-近中, III-A-远中, III-A-垂直, III-A-水平, III-A-倒置,
   III-B-近中, III-B-远中, III-B-垂直, III-B-水平, III-B-倒置,
   III-C-近中, III-C-远中, III-C-垂直, III-C-水平, III-C-倒置
   ```
   （规则：关系 I→II→III，位置 A→B→C，角度 近中→远中→垂直→水平→倒置。）
   实际标注中只用到其中一部分类别，正常。
3. **导入预标注**：用预训练模型生成的 `annotated_presets/labels/` 预标注
   （X-AnyLabeling 支持导入 YOLO 格式），逐个检查：
   - 框是否对准整颗智齿 → 拖动修正
   - 类别是否选对 → 重新选择 Winter 组合
   - 漏检的智齿 → 手动补框
4. 导出：YOLO 格式（每图一个同名 txt，每行 `类别ID cx cy w h`）。
   导出的目录结构与 `images/` 对应，命名为 `labels/`。

## 4. 质检清单（交标前自查）

- [ ] 每一颗智齿都有框（包括完全埋伏的），没有漏标
- [ ] 没有把第二磨牙、残根、多生牙当成智齿框进去
- [ ] 框紧贴整颗牙（含牙根），未切掉牙根尖端
- [ ] 左右两侧都标了
- [ ] 拿不准的角度/位置不要乱选，若确实无法判断，单独记下来告诉负责人
- [ ] 类别名拼写与上表完全一致（X-AnyLabeling 里直接从列表选，不要手敲）

## 5. 参考图

标注前先找 2-3 张典型片（近中阻生、水平阻生、垂直阻生、II 类、III 类等）
与老师确认判读标准，统一后再开始批量标注。

## 6. 常见问题

- **第二磨牙缺失时怎么判位置？** 参照对侧同名牙的咬合平面，或按残存牙槽嵴
  顶水平近似判断，并在备注里说明。
- **牙冠在支内、牙根在支外（或反之）怎么判关系？** 以牙冠位置为主：
  牙冠大部分被下颌支遮挡即 II/III 类。
- **近中水平 vs 近中倾斜 怎么区分？** 长轴与垂直方向夹角约 >45° 按水平，
  <45° 按近中/远中倾斜处理。
